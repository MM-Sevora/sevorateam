# Sevora Hub - Team Onboarding Guide

## Overview
Sevora Hub is a comprehensive team management platform that includes project management, marketing, HR, finance, and collaboration tools.

---

## Phase 1: Initial Setup (Admin - Day 1)

### 1.1 Access & Login
- [ ] Go to: `https://teams.sevora.com`
- [ ] Login with admin credentials
- [ ] Verify all modules are accessible

### 1.2 Configure Organization Settings
- [ ] Go to **Admin** → **System Settings**
- [ ] Set company name and logo
- [ ] Configure timezone
- [ ] Set up email notifications (SendGrid)

### 1.3 Set Up User Roles & Permissions
| Role | Access Level |
|------|--------------|
| Super Admin | Full access to all modules |
| Admin | Manage users, settings |
| Manager | Department-level access |
| Team Lead | Project-level access |
| Member | Task-level access |
| Viewer | Read-only access |

## Phase 2: User Management (Admin - Day 1-2)

### 2.1 Create User Accounts

## Notification Settings Guide

### Available Alerts:
| Alert Type | Default | Recommended |
|------------|---------|-------------|
| Task assigned | ✅ On | Keep On |
| Task due soon | ✅ On | Keep On |
| Task overdue | ✅ On | Keep On |
| Meeting reminder | ✅ On | Keep On |
| Goal updates | ⚙️ Optional | Managers: On |
| Weekly digest | ⚙️ Optional | All: On |

### To Configure:
1. Go to **Profile** → **Notification Settings**
2. Toggle alerts on/off
3. Choose channels (In-app, Email, Teams)
